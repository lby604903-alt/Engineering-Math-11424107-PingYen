# Problem 5 - RC Low-Pass Filter (Laplace Transform)

## Step 1: Establish the Differential Equation

An RC low-pass filter is a first-order linear system. According to the circuit model, the relationship between the input signal and the output voltage is described by the following differential equation.

```math
RC\frac{dy(t)}{dt}+y(t)=f(t)
```

The input signal is

```math
f(t)=\left[\sin(10t)+0.5\sin(1000t)\right]u(t)
```

where

- \(\sin(10t)\) is the desired low-frequency signal.
- \(0.5\sin(1000t)\) is the high-frequency noise.
- \(u(t)\) is the unit step function, indicating that the signal is causal.

Since the capacitor is initially uncharged, the initial condition is

```math
y(0)=0
```

Therefore, the differential equation together with the initial condition completely describes the RC filter system.

---

## Step 2: Substitute the Given Circuit Parameters

The resistance and capacitance are given as

```math
R=1000\Omega
```

```math
C=1\mu F
=1\times10^{-6}F
```

First, calculate the RC time constant.

```math
RC
=
1000\times10^{-6}
```

```math
RC
=
0.001
```

Substituting this value into the differential equation gives

```math
0.001\frac{dy(t)}{dt}
+y(t)
=
\left[\sin(10t)+0.5\sin(1000t)\right]u(t)
```

This equation will be transformed into the Laplace domain in the next step.

---

## Step 3: Apply the Laplace Transform

Apply the Laplace transform to both sides of the differential equation.

Using the differentiation property

```math
\mathcal L
\left\{
\frac{dy(t)}{dt}
\right\}
=
sY(s)-y(0)
```

Since the initial condition is

```math
y(0)=0
```

the transformed derivative becomes

```math
\mathcal L
\left\{
\frac{dy(t)}{dt}
\right\}
=
sY(s)
```

Next, apply the Laplace transform to each term in the differential equation.

```math
\mathcal L
\left\{
0.001\frac{dy(t)}{dt}
+y(t)
\right\}
=
\mathcal L
\left\{
\sin(10t)+0.5\sin(1000t)
\right\}
```

Substituting the transformed derivative gives

```math
0.001sY(s)+Y(s)
=
\mathcal L
\left\{
\sin(10t)
\right\}
+
0.5
\mathcal L
\left\{
\sin(1000t)
\right\}
```

Using the standard Laplace transform formula

```math
\mathcal L
\left\{
\sin(at)
\right\}
=
\frac{a}{s^2+a^2}
```

we obtain

```math
0.001sY(s)+Y(s)
=
\frac{10}{s^2+100}
+
\frac{500}{s^2+1000000}
```

Factor out the common term \(Y(s)\).

```math
Y(s)(0.001s+1)
=
\frac{10}{s^2+100}
+
\frac{500}{s^2+1000000}
```

Finally, divide both sides by \(0.001s+1\).

```math
Y(s)
=
\frac{
\dfrac{10}{s^2+100}
+
\dfrac{500}{s^2+1000000}
}
{0.001s+1}
```

Separate the expression into two terms.

```math
Y(s)
=
\frac{10}{(s^2+100)(0.001s+1)}
+
\frac{500}{(s^2+1000000)(0.001s+1)}
```

The first term represents the low-frequency component, while the second term represents the high-frequency component. These two parts will be solved separately in the following steps.
